## 4. 状态验收矩阵

| 场景 | 输入 / 注入方式 | 实际用户结果 |
| --- | --- | --- |
| 正常请求 | Fixture 正常响应 | 首批 50 条；继续加载后 59 条且无重复；单集搜索命中 1 条，节目搜索命中 20 条 |
| 慢请求 | 历史接口延迟 1200ms | 103ms 出现稳定加载态，1387ms 出现 50 条有效内容；未暴露虚假空态 |
| 初始失败 | 首次历史请求返回 500 | 只显示历史局部错误；不显示空态；单独重试恢复 50 条 |
| 搜索失败 | 首次带查询请求返回 500 | 原 50 条保持可用；单独重试后收敛为 1 条服务端结果 |
| 分页失败 | 首次游标请求返回 500 | 原 50 条保持可用；单独重试后得到 59 条唯一记录 |
| 正常空历史 | 首次请求返回合法空结果 | 请求成功后才显示“还没有完成记录”，加载态已结束 |
| 滚动返回 | 加载 59 条后滚到末项再回首项 | 59 条全部保留，仅发生首批与分页两次历史请求 |
| 缓存回访 | 同一会话刷新 | 本功能未新增缓存；重新读取首批 50 条，加载态与结果一致 |
