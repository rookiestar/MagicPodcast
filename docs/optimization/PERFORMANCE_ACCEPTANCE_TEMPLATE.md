## 11. 收口判断

逐项确认：

- [ ] 用户体验不变量得到证明；
- [ ] 正常、慢、失败、首次访问均已覆盖；
- [ ] 冷态和热态分别测量；
- [ ] 有效内容时间和空态暴露率已记录；
- [ ] 缓存、超时和重试边界明确；
- [ ] 产品行为变化已完成人审；
- [ ] 自动化检查通过，或跳过项已说明；
- [ ] 生产运行版本与目标提交一致；
- [ ] 阻塞门禁持续通过；
- [ ] 回退路径可用；
- [ ] 未执行的生产、数据库或外部操作没有写成已完成。

专项状态：

- [ ] 可关闭；
- [ ] 代码完成，等待生产验收；
- [ ] 生产已回退，需要继续诊断；
- [ ] 被人审、环境或外部依赖阻塞。

## 12. 最终汇报模板

```text
改动：
用户现在多久能看到什么；慢或失败时仍保留什么。

验证：
正常、慢、失败、首次访问分别观察到什么；关键指标前后变化。

状态：
本地 / 生产运行哪个版本，专项是否可关闭。

剩余风险：
未执行检查、持续观察、外部依赖或人审事项。
```
