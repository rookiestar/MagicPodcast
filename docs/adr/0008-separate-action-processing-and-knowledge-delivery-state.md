# 分离行动队列、加工运行与外部交付状态

Focus 只表达单集具备加工资格，不在入列瞬间启动加工；手动和定时入口共同创建独立的加工运行。加工运行生成并保存规范化逐字稿与单集纪要，随后每个外部知识中心各自记录外部交付结果。

三类状态互不覆盖：移动或完成单集不会改写既有加工记录，运行失败或取消不会改变 Focus/Done，某个知识中心交付失败也不会把本地加工降级为失败。该分离会增加少量持久状态，但避免把用户意图、计算过程和第三方可用性耦合成一个不可解释的状态机。

详细行为见 [Focus 自动化播客加工与单集助手 Spec](../research/FOCUS_AUTOMATED_PODCAST_PROCESSING_SPEC_2026-08-24.md)。
