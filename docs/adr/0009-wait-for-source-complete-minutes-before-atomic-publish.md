# 源端完整后才原子发布飞书智能纪要

新加工在 Summary、Transcript 与逐字稿时间轴就绪后，进入独立的智能纪要等待，而不是把当时已有的核心产物标为完成。等待窗口从核心内容首次就绪起固定 30 分钟，写入受保护检查点；普通轮询与服务重启不得重置截止时间。只有关联 Note 可读、已存在的目标区块均可解析、源端存在的画板已导出并校验后，才把新产物原子切换为当前版本。

飞书真实未生成的决策、金句、链接或画板保持为空，并由页面隐藏；MagicPodcast 不补写这些区块。未知模板、无法解析的非空目标区块、源端存在但取不到的画板、完整性失败或等待超时使本次运行失败，上一成功 artifact 仍为当前版本，首次加工不发布草稿。用户发起的“重新同步”复制安全检查点、复用原妙记身份并开启新的 30 分钟窗口，不得回到 Drive 上传或 Minutes 创建。

该选择用最多 30 分钟的延迟，换取完成状态与页面内容忠实于飞书源端，并保住 #247/#248 已确认的不可变产物、上一成功版本和远端身份不外泄边界。更快可读的核心-only 发布会把晚到的画板和区块永久锁在已发布快照之外，因此被明确放弃。
