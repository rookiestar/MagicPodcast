# 将 Done 与行动队列分离并保留完成事实

Inbox、Focus、Someday 是表达未来投入意图的行动队列；Done 是用户明确确认“不再需要继续投入注意力”的当前完成状态，不再作为可长期积累和手动排序的同类队列。Inbox 工作台只投影最近 168 小时内、最多 20 条且当前仍为 Done 的“最近完成”，完整记录进入独立的完成历史。

每个单集只保留一条完成事实，重复完成刷新最近完成时间；重新处理或标记不感兴趣不抹去该事实，删除来源单集才一并删除。这样既避免 Done 泳道无限增长，又保留长期个人信号，同时不引入完整完成事件流水。

该决策取代 Done 与其他三条队列同等持久排序的语义。既有 Done 顺序不再影响展示；旧数据只从当前 Done 单集及其既有完成时间初始化，无法重建已被后续状态覆盖的历史完成事实。

详细行为见 [Inbox Done 与完成历史设计](../research/INBOX_DONE_HISTORY_DESIGN_2026-08-23.md)。
