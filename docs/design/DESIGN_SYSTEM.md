# MagicPodcast 设计系统规范

状态：现行方向；2026-09-25 根据规范 review、当前页面与用户确认修订。
组件是否完成统一，以专项验收记录和实际实现为准。

## 1. 视觉方向

保留暖纸色、墨色、橙色强调和编辑式阅读气质，减少纹理、粗边框、硬阴影及重复装饰。
列表服务快速判断，工作台服务处理，长文服务阅读；密度随任务变化，不把所有页面压成同一行高。

- 颜色与公共样式维护在 [globals.css](../../frontend/src/app/globals.css)，页面优先复用现有 `editorial-*` 类。
- 字体、字号、行高与富文本比例只维护于 [TYPOGRAPHY.md](TYPOGRAPHY.md)。
- 业务术语与状态语义遵循 [CONTEXT.md](../../CONTEXT.md)。
- 本轮 review、已确认范围与剩余覆盖见 [专项记录](FRONTEND_CONSISTENCY_2026-09-25.md)。

## 2. 色彩、表面与层级

| 用途 | Token / 实现值 | 使用原则 |
| --- | --- | --- |
| 页面底色 | `--editorial-canvas` / `#f8f5ed` | 暖纸底；首屏回退同色 |
| 内容表面 | `--editorial-surface` / `#fffaf2` | 表单、阅读容器；避免层层套卡片 |
| 主文字 | `--editorial-ink` / `#28231e` | 正文与核心操作 |
| 次要文字 | `--editorial-muted` / `#6f6559` | 辅助说明，不用极浅色承载必要信息 |
| 分隔 | `--editorial-rule` / `#d8cfc0` | 常规 1px；较强分隔只用于主要层级 |
| 主按钮 | `--editorial-primary` / `#ff8a3d` | 黑色文字；当前任务的主要提交操作 |
| 主按钮悬停 | `--editorial-primary-hover` / `#f47a2f` | 保持文字可读 |
| 键盘焦点 | `--editorial-focus` / `#1768d0` | 清楚的 2px 轮廓，不只用 hover 表达 |

这些 Token 是公共色板的单一实现入口。旧页面仍有硬编码色值；按触及组件逐步复用，
不靠不断追加宽泛选择器覆盖。告警、成功、队列身份色与标签自选颜色保持业务语义。

纸纹仅作为弱背景；弹窗以平整表面为主。阴影表达浮层关系，取消偏移很大的装饰性硬阴影。
浅色编辑界面是本轮基线；尚未完成全站深色模式验收，不宣称所有页面已支持同等深色体验。

## 3. 间距与操作目标

- 以现有 4 / 8 / 12 / 16 / 20 / 24px 间距组织内容。列表和表单默认紧凑，避免统一套用 `py-20`、`mb-16` 或卡片 `p-8`。
- 主要点击目标至少 44px。图标本身可小于 44px，但命中区域和键盘焦点区应足够。
- 桌面工作流列表当前 58px 行高、20px 分组间隔可作为紧凑管理列表参考，不能直接套给阅读卡片。
- 手机端隐藏顶部导航时，同时取消桌面导航占位；底部导航与安全区域不能盖住操作。

## 4. 按钮与选择状态

复用 `.editorial-btn` 的 primary、ghost、danger、link 等现有变体。
每组只有一个主要提交动作；取消与返回为次级，破坏性操作与普通操作有明确区分。
弹窗底部动作靠右、间距 8px，窄屏允许换行。纯图标控件必须保留可访问名称与 hover 提示。

单选分段控件用墨色实底、浅色文字表示当前项；内容页签用下划线表示当前面板。
多选条件、当前导航、警告状态各保留相应语义，不只靠颜色表达。使用 `aria-pressed`、
`aria-selected`、`aria-current` 中与控件实际角色匹配的属性。

## 5. 核心交互合同

- 单集标题默认进入站内单集工作台；外部目的地明确写“原节目”，音频与视频沿用独立图标入口。
- 简介阅读是次要动作；标题、正文展开、外链目的地不应靠“查看详情”这种模糊文案区分。
- 手机行动工作台在 767px 及以下使用顶部队列切换、单栏浏览；切换显示当前数量，保留每栏滚动位置，支持带 `queue` 的入口。桌面仍可并排比较与拖放。
- Done 是完成状态，展示的是最近完成；上述切换不改变行动队列、完成事实、撤销和 Focus 软上限的业务含义。
- 弹层打开后焦点进入其内部；Tab / Shift+Tab 不应意外退出，Escape 关闭最内层可关闭浮层，关闭后恢复触发入口与阅读位置。独立页面不套用模态焦点圈。
- 提交失败保留输入和可读内容；读取失败提供局部重试；加载状态应告知正在发生什么。不得以清空内容换取轻量外观。

## 6. 动效与排版

只用解释状态变化的短过渡；加载指示器可以转动或闪动，不能笼统禁用 `animate-spin` 或骨架屏。
尊重 `prefers-reduced-motion`，让用户能直接看到状态。字号与字体角色、富文本密度、
中文真实字重和字体加载规则遵循 [TYPOGRAPHY.md](TYPOGRAPHY.md)。
