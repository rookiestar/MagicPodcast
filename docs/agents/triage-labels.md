# 任务状态标签

工程技能使用五种标准状态。MagicPodcast 在 GitHub Issues 中直接使用同名标签，不创建重复或同义标签。

| 标准状态 | GitHub 标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 需要维护者评估 |
| `needs-info` | `needs-info` | 等待报告者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 内容完整，无需额外背景即可由 Agent 执行 |
| `ready-for-human` | `ready-for-human` | 需要人工实施或决策 |
| `wontfix` | `wontfix` | 已决定不处理 |

技能提到某个标准状态时，应使用表中对应的 GitHub 标签。若未来更改标签名称，应先更新本表，再使用新名称。
