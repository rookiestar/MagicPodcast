# #414 清单重复条目归并验收

日期：2026-09-14。基线：33c0bbd（#413 合并版本）。本记录仅描述本地实现与验证，未提交或部署。

## 已实现

- 三种已支持来源在原始条目结构校验后共用归并处理。按外部单集 ID 保留首次位置与元数据，推荐语以完整文本精确去重并按源顺序用空行连接。
- 同一单集出现不同的非空节目 ID 时拒绝；任何重复项缺少可用音频快照时，归并结果不提供音频，私密标记不被抹除。
- 导入与刷新预览返回 `source_item_count`、`duplicate_item_count`；`read_count` 和条目数组均为唯一单集。专题预告位仍不计为已读取单集条目。
- 仅有重复时显示归并提示。预览及详情推荐语保留换行。无需 schema 变更，不回填历史数据。
