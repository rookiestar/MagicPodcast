# #360 / #361 人物弹层 P2 修复验收

日期：2026-09-12。范围：[#360](https://github.com/rookiestar/MagicPodcast/issues/360)（局部匹配管理入口错误定位首段）、[#361](https://github.com/rookiestar/MagicPodcast/issues/361)（默认关闭弹层仍创建 Portal 阻断播放器 SSR）。两者均为 PR #359（Spec [#355](https://github.com/rookiestar/MagicPodcast/issues/355)）合并后审查发现的 P2，不重做人物识别与导航。

## 修复内容

- #361：`useTranscriptPeople` 的管理弹层与编辑器 Portal 延迟到客户端挂载后创建（`portalHost` 状态 + 挂载 effect）。SSR 渲染不再触达 `document.body`；挂载后 Portal 保持挂载，关闭仍只 `display:none` 隐藏，审阅滚动与 details 展开状态不丢失（不回退为关闭即卸载）。
- #360：未匹配 Speaker 行按已应用人物生成入口，每个「修改『人物』」按钮定位到该人物实际已应用的片段（混合多人归属不再任取首段）；行徽标区分「已应用 / 局部已应用 / 姓名待确认」，摘要区分总发言数、已应用数与待确认数；「填写姓名」路径保持不变。
- `TranscriptPeople.module.css`：`.unmatched` 加 `flex-wrap`，多入口在窄屏不挤压摘要。
